九連環 × DQN

同一套規則跑在兩邊：web/engine.js 給你玩，ml/env.py 給 agent 訓練。這個謎題有已知的最優解（341 步），所以隨時知道 AI 離最優差多少。

規則（只有兩條）

  • 環 1（最右邊）隨時可以上或下。
  • 環 k 可以動，若且唯若環 k−1 在桿上、而且環 1…k−2 全都不在。

結果就是：任何時候最多只有 2 個環動得了。整個狀態空間 2⁹ = 512 個狀態排成一條線， 你只能往前或往後一步。全上的狀態離終點 341 步——中途一定要把已經拿下來的環再裝回去， 所以「一路往前拆」的貪心策略必死。

AI 的 Q 值（牠覺得動哪個環值多少）

Q(s,a) = 「現在動這個環，之後累積起來大概能拿多少分」。灰色那些是規則上動不了的環， 訓練時它們被壓成 −1e9，所以網路對它們輸出什麼都無所謂。真正在比的只有那 1–2 條藍色的。

訓練曲線

橫軸是收集了幾個 transition。因為狀態只有 512 個而且環境是決定性的， 評估直接窮舉全部起點——沒有取樣雜訊，這條線是實線不是估計值。

怎麼用

1. 這頁要用小型伺服器開（file:// 不能 fetch）：
在專案根目錄跑 python -m http.server 8000，然後開 http://localhost:8000/web/

2. 訓練 agent：cd ml && python train.py

3. 匯出給網頁：python export_policy.py，重整這頁就會看到 DQN 模式。

4. 跟基準線比：python evaluate.py；跨語言對帳：node web/_parity_test.mjs

操作：點環或按數字鍵 1–9 動那個環。
