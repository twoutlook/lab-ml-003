01 · 規則The rules

只有兩條，但足以逼你後退Two rules, and they force you backwards

RULE 1

最外面那個環，隨時可以上、可以下。 The outermost ring can always go on or off.

RULE 2

環 k 要動，必須環 k−1 還在桿上，而且比它更外面的全都不在。 Ring k moves only if ring k−1 is on the bar and every ring outside it is off.

推論比規則本身有意思：任何時候最多只有兩個環動得了。 所以 2⁹ = 512 個狀態其實排成一條直線，你只能往前一步或往後一步。 全部套上的狀態，落在離終點 341 步的地方。 The consequence is more interesting than the rules: at any moment at most two rings can move. So the 512 states form a single path — you can only step forward or back along it. The all-on state sits 341 steps from the end.

512 個狀態排成一條線All 512 states, in a line

gray code

距離可以直接算出來——把九個 bit 當成格雷碼解碼，得到的整數就是剩餘步數。 合法動作恰好讓這個整數加一或減一。所以九連環其實是一個九位元計數器， 而「解開它」就是從 341 數到 0。 The distance is computable: read the nine bits as a Gray code and the decoded integer is exactly how many moves remain. Every legal move changes it by ±1. The puzzle is a nine-bit counter, and solving it means counting 341 down to zero.

這也解釋了為什麼「能拿就拿」必死：341 步裡有一半是在把已經解下來的環裝回去。 一個永遠不肯後退的策略，在 511 個起點裡只解得開一個。 It also explains why the intuitive strategy dies: half of those 341 moves put rings back on. A policy that never goes backwards solves exactly one of the 511 starts.

02 · 踩到的坑The trap

照教科書寫，會學不起來Following the textbook makes it unlearnable

341 步只有最後一步有分，這叫稀疏獎勵。標準解法是 potential-based reward shaping： 用一個位能函數 Φ，讓每走對一步就有回饋。 Only the last of 341 moves pays anything — a sparse reward. The standard fix is potential-based reward shaping: a potential Φ that pays off on every correct step.

F(s,s′) = shaping × ( γs · Φ(s′) − Φ(s) )Φ(s) = −distance(s)

Ng et al. (1999) 的保證要求 γs 等於訓練用的折扣率，這樣最優策略才不會被改掉。 照做的結果是完全學不起來——原因在展開之後：因為 Φ 跟距離成正比， 會多出一項 (1 − γs) · d。d 最大 341，γs = 0.95 時這一項有 17， 是真正帶方向的那個 ±1 的十七倍。走錯邊也拿正分。 Ng et al. (1999) require γs to equal the training discount for the guarantee to hold. Doing that fails completely. Expand it: Φ is proportional to distance, so a term (1 − γs) · d appears. With d up to 341 and γs = 0.95 that term is 17 — seventeen times the ±1 that actually carries direction. Moving the wrong way still pays.

同一份程式，只改 shaping 的一個常數Same code, one shaping constant changed

300k transitions

理論保證的前提沒滿足的時候，要知道它為什麼沒滿足。 When a guarantee's precondition fails, know why it fails.

這裡把 γs 設成 1，換來「走對一步就加分」，代價是理論保證消失。 所以才必須窮舉 511 個起點去驗證它真的走出最優解，而不是相信它。 Setting γs = 1 buys a clean ±1 signal and gives up the guarantee. That is exactly why the evaluation enumerates all 511 starts instead of trusting the theory.

03 · 結果Results

窮舉，不是抽樣Enumerated, not sampled

環境完全沒有隨機性，狀態又只有 512 個，所以評估是從每一個非終點狀態各解一次。 沒有 seed，沒有信賴區間可談。 The environment has no randomness and only 512 states, so evaluation runs once from every non-terminal state. No seeds, no confidence intervals to argue about.

四個策略 × 511 個起點Four policies × 511 starts

也要照實說：這件事其實不需要神經網路。512 個狀態直接開一張 Q 表， 表格式 Q-learning 五千局就收斂到 100% 最優，比 DQN 快也比 DQN 準。 這個專案值得學的是方法——動作遮罩、shaping、窮舉式評估——不是結果。 In fairness: this problem does not need a neural network. With 512 states you can hold the whole Q-table in memory; tabular Q-learning converges to 100% optimal in about five thousand episodes, faster and more reliably than DQN. What is worth taking from this project is the method — action masking, shaping, exhaustive evaluation — not the result.

04 · 怎麼組起來的How it is built

兩份實作，一套規則Two implementations, one rulebook

瀏覽器裡的 engine.js 和訓練用的 env.py 是同一套規則的兩份實作， 兩邊都讀同一份 shared/config.json。因為環境是決定性的，跨語言對帳可以要求 逐位相同：JS 端跑過 511 個起點的三個數字，必須跟 Python 端一模一樣，差一步就是 bug。 engine.js in the browser and env.py in training are two implementations of one rulebook, both reading the same shared/config.json. Because the environment is deterministic, the cross-language check demands bit-identical results: the JS run over all 511 starts must match Python exactly. One step off is a bug.
